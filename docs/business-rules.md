# Culmen — բիզնես կանոնների աուդիտ

Աուդիտը՝ 2026-10-31։ Փուլ 1-ի փոփոխություններից հետո թարմացվել է։

«Բազայում» նշանակում է, որ կանոնը կգործի նաև ապագա մոբայլ հավելվածի համար։ «Միայն սերվերում» նշանակում է, որ կանոնը գրված է Next.js-ի կոդում, և մոբայլը այն կստանա միայն նույն API-ով աշխատելու դեպքում։

## Հին փաթեթային սահմաններ

Հանված են (փուլ 1, միգրացիա 0084)։ START-ն անժամկետ է, Advanced-ի ժամկետն ավարտվելիս ակումբն անցնում է START-ի, իսկ PRO-ն սառեցված է։

## Արագության և կայունության չափումներ

Չափված է Երևանից, կենդանի կայքի վրա։ Cloudflare-ի թվերը վերջին 7 օրվա են։

| Ինչ | Արդյունք |
|---|---|
| Cloudflare-ի պատասխան առանց բազայի | 0.06–0.07 վրկ |
| Գրեթե ստատիկ էջեր (`/faq`, `/terms`, `/about`) | 0.4–0.8 վրկ |
| `/places` | 1.3–1.5 վրկ |
| `/tours`, `/clubs`, `/calendar` | 1.9–3.5 վրկ |
| Գլխավոր էջ | 1.9–4.8 վրկ |
| Մեկ հարցում բազային | 0.35–0.47 վրկ |
| Հաջող հարցումներ | 13 558 |
| CPU սահմանից ձախողված (`exceededResources`) | 816 (մոտ 5.5%) |
| Այցելուի կողմից ընդհատված | 406 |

## Հիմնական պատճառները (ստուգել փոփոխությունից առաջ)

1. **Քեշ չկա։** `open-next.config.ts`-ում պահեստ կարգավորված չէ, ուստի կոդի `unstable_cache`-ը, ամենայն հավանականությամբ, հարցումների միջև չի պահպանվում։
2. **Բոլոր էջերը դինամիկ են։** Ամեն էջ ամեն անգամ նորից է կառուցվում (`Cache-Control: no-store`)։
3. **Շատ և դանդաղ հարցումներ բազային։** Գլխավոր էջը մի քանի տասնյակ տվյալ է բերում, իսկ մեկ հարցումն արդեն մոտ 0.4 վրկ է։
4. **Անվճար պլանի 10ms CPU սահմանը։** Իրական էջերի P50-ը մոտ 12ms է։
